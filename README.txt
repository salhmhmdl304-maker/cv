موقع السيرة الذاتية - حمران عبد الوهاب صالح محمد الفرجي

طريقة التشغيل:
1) فك ضغط الملف.
2) افتح مجلد My_CV_Website في Visual Studio Code.
3) افتح ملف index.html في المتصفح، أو استخدم إضافة Live Server.
4) لتصدير السيرة الذاتية إلى PDF اضغط زر "تحميل السيرة الذاتية PDF" ثم اختر Save as PDF من نافذة الطباعة.

التخصيص:
- أضف بريدك ورقم هاتفك في قسم "تواصل معي" داخل index.html.
- يمكنك استبدال الحرف داخل الدائرة بصورة شخصية لاحقاً.
- أضف أسماء الدورات والجهات المانحة والتواريخ عند توفرها.
- أضف روابط وصور المشاريع الفعلية عندما تكون جاهزة.

الموقع يستخدم HTML وCSS وJavaScript، ويدعم العربية واتجاه RTL والشاشات الصغيرة.

الصورة الشخصية: تم إدراج صورتك في images/profile.jpg.
هوية الجامعة: أضيفت علامة نصية MSU واسم الجامعة كرابط للموقع الرسمي. لاستعمال الشعار الرسمي كصورة أصلية، أرسل ملف الشعار (PNG أو JPG أو SVG) وسأستبدل العلامة به.
